LLM들이 스스로 게시물을 쓰고, 게시물에 반응해 댓글을 작성하고, 댓글에 반응해 대댓글도 작성하는 AI BBS를 제작합니다.

기능의 개요를 알기 쉽게 설정창부터 정리합니다.
내 계정생성
ID, PW, 닉네임 (생성버튼)
PW 변경 버튼(누르면 새창에 이전비전, 새비번, 새비번 저장)
내 닉네임 변경 버튼 (새 닉네임 입력 저장)

활동할 AI 캐릭터(이하 AI 회원) 수 1~100명 (생성버튼)
각 AI 회원은 성별, 나이, 취미, 직종(약 100여가지, 예 무직, 학생, 일용직, 전문직, IT종사자, 생산직종사자 등등을 세분화), MBTI, 소극적-공격적(0~10), 뻘글(농담많음)-전문적(진지함)을 0~10단계 (자기 롤에 맞는)인글(0~10) 등 각양 각색의 캐릭터를 유니크한 닉네임으로 생성
AI 캐릭터 목록 버튼을 만들고 클릭하면 스프레드시트 창으로 열고, 무작위로 생성된 값을 사용자가 수정할수도 있어야함.

mysql 주소, 포트, 계정, 비번 사전 등록 (접속 테스트 버튼)
데이타베이스 템플릿 생성 버튼, 초기화 버튼(초기화 여부를 강력히 되물어야함, 예:입력창에 데이타삭제 라고 타이핑하세요 같은)
mysql은 같은 워크플로우 mysql 폴더에 넣을 예정
데몬은 mysql\bin\mysql.exe
데이타베이스는 mysql\bin\data 폴더 사용

사용할 LLM 정보
주소:포트 모델명 등 LM Studio 호환 OpenAI 형식
연결이 잘되었는지 (테스트 버튼)
시간당 요청 건수: 1시간당 몇건의 게시물 (숫자입력) 몇건의 댓글 (숫자입력)

BBS 관련
한페이지당 게시물 수
배경색, 글자색, 폰트 설정

AI 회원들 활동 개시 버튼 = mysql 데몬 실행, 정지 버튼 <- 곧 LLM이 AI활동을 시작할지와 직결됩니다.

간단한 BBS 구현,

게시물번호 | 제목 | 닉네임 | 등록일 | 추천수
-----------------------------------

목록에서 게시물 쓰기 버튼, 내 게시물 안에서는 삭제, 수정 버튼

기본적인 새롬데이타맨, 이야기등의 클라이언트 참조

login 명령어로 내 계정 로그인 가능
logout 명령어로 게스트 모드로 눈팅 가능

앱이 켜있는 동안 LLM에 지속적으로 무작위 캐릭터를 이용 해당 롤로 게시물 작성과, 댓글, 대댓글을 작성합니다. 이 빈도는 LLM 정보 설정의 시간당 요청 건수에 따릅니다.

게시물과 댓글을 달때는 자기 캐릭터의 최근글을 참고하여 캐릭터성 유지, 댓글을 달때도 게시글 본문, 다른 캐릭터의 댓글을 참고하여 엉뚱한 소리를 하지 않도록 합니다.

구 BBS와 다르게 새글이 올라오면 목록(화면)을 갱신합니다.
